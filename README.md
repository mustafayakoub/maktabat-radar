# رادار المكتبات · maktabat-radar

**ما استجدّ في مكتباتنا على الهارد والسيرفر — في صفحةٍ واحدةٍ خفيفةٍ سريعة.**

يسألُ فهرسَ [Everything](https://www.voidtools.com/) حيًّا فيعطيك البحثَ في ملايينِ
الملفّاتِ في أجزاءٍ من الثانية، ويحفظُ **سجلَّ وصولٍ** خاصًّا به ليجيبَ عمّا لا يعرفه
Everything ولا أيُّ فهرس: **متى وصلَ هذا الكتابُ إلينا نحن؟**

## لماذا سجلُّ وصولٍ أصلًا؟

لأنّ تاريخَ تعديلِ المِلفِّ يكذبُ في أهمِّ حالةٍ عندك: كتابٌ نسختَه اليومَ من قرصٍ أو
حمّلتَه من الشبكةِ يحملُ تاريخَ منبعِه (٢٠٢١ مثلًا)، فلا يظهرُ في «جديدِ اليوم» أبدًا.
فالرادارُ يمسحُ دوريًّا ويقارنُ لقطتين: ما لم يكن في المسحِ السابقِ وصارَ في هذا فهو
**واصلٌ** بشهادةِ الرادارِ نفسِه. والمقياسان معروضان جنبًا إلى جنبٍ ولا يُخلَطان.

| زمنُ بحثٍ عربيٍّ متسامح | ٠٫٩–٢٫٠ ثانية |
| فتحُ الصفحة | ٠٫٥٧ ثانية |

## التشغيل

لا تبعيّاتٍ أصلًا — بايثون ٣٫١١+ ومكتبتُه القياسيّةُ وحدَها، وEverything مشتغلًا.

```
python -m maktabat.scan        # مسحٌ يكتبُ سجلَّ الوصول (الأوّلُ خطُّ أساس)
python -m maktabat.server      # الصفحةُ على http://127.0.0.1:8731
python -m maktabat.verify --server http://127.0.0.1:8731   # الحارس
```

أو بالنقر: `tools\radar.cmd` للصفحة، و`tools\scan.cmd` لمسحةٍ واحدة.

**وللرصدِ الآليِّ كلَّ ساعة** (وبه وحدَه يصيرُ «الجديدُ خلال ساعة» ذا معنًى):

```
powershell -ExecutionPolicy Bypass -File tools\install_task.ps1
```

## الإعدادات

كلُّ شيءٍ في `config.json`: الجذورُ المرصودةُ وصيغُ الكتبِ وما يُستثنى والمنفذ.
الجذورُ تُكتشَفُ أوّلَ مرّةٍ من الجهاز (مشاركةُ السيرفرِ وكلُّ قرصٍ غيرِ قرصِ النظام).

## كيف يعمل

| السؤال | من يجيب | لماذا |
|---|---|---|
| ابحثْ لي عن كتاب | Everything حيًّا عبر IPC | أحدثُ من أيِّ لقطة، وبلا فهرسٍ ثانٍ نبنيه |
| ما وصلَ هذه الساعة؟ | سجلُّ الوصولِ المحلّيّ | الفهرسُ لا يعرفُ متى وصلَ إلينا |
| ما اختفى؟ ما تغيّر؟ | سجلُّ الوصول | فرقُ لقطتين |
| كم عندنا وأين؟ | مخزونٌ يُحسَبُ في ذيلِ المسح | جمعُ ٣٫٥ ملايينِ صفٍّ في كلِّ طلبٍ هدر |

الجسرُ إلى Everything استعلامُ `WM_COPYDATA` مباشرةً (`everything.py`) — **بلا `es.exe`
ولا `Everything64.dll` ولا خادمِ HTTP ولا تغييرِ أيِّ إعدادٍ في برنامجك**.

## التسامحُ العربيُّ في البحث

مقيسٌ أنّ Everything يطوي همزاتِ الألفِ من نفسِه («الاعجاز» = «الإعجاز» ٥٬٦٨٧ لكلتيهما)،
و**لا يطوي** التشكيلَ ولا الياءَ المقصورةَ ولا التاءَ المربوطةَ ولا التطويلَ ولا الياءَ
الفارسيّة. فالرادارُ يبني تعبيرًا نمطيًّا لما لا يطويه وحدَه:

| الكلمة | بلا تسامح | بتسامح |
|---|---|---|
| مُحَمَّد | ٢٩ | ٢٣٧٬٦١٧ |
| الفتاوى | ٣٬٧١٧ | ٣٬٩٧٤ |
| تفسير | ٩٢٬٨٢١ | ٩٣٬٤٨٩ |

## الخصوصيّة

يُنصَتُ على `127.0.0.1` وحدَه، ويُرفَضُ كلُّ طلبٍ لا يأتي من هذا الجهاز، ولا يُفتَحُ
مسارٌ خارجَ الجذورِ المرصودة. ولا يخرجُ من جهازك شيءٌ البتّة.
